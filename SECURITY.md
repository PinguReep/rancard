# Sécurité

## Signaler une vulnérabilité

N'ouvrez pas de ticket public. Utilisez le signalement privé de GitHub :
https://github.com/PinguReep/rancard/security/advisories/new

Indiquez le composant touché (app mobile ou workflows GitHub Actions), les
étapes pour reproduire et l'impact. Réponse sous 7 jours, en français ou en
anglais.

## Périmètre

- Le code de la branche `main` ; aucune autre version n'est maintenue.
- Ce dépôt ne contient que l'app mobile. L'app distribuée sur TestFlight tourne
  en mode démonstration, avec des données fictives stockées sur l'appareil.
- Hors périmètre : services tiers (Apple, Expo, GitHub), déni de service,
  ingénierie sociale.

N'accédez à aucune donnée qui ne vous appartient pas et laissez un délai
raisonnable avant toute publication. Pas de programme de récompense.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub private vulnerability
reporting: https://github.com/PinguReep/rancard/security/advisories/new
